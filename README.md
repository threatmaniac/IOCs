
# Malware IOC Repository

A centralized collection of Indicators of Compromise (IOCs) associated with malware and malicious cyber activities.

This repository aims to document, organize, and share threat intelligence indicators to support malware research, threat hunting, detection engineering, and defensive security operations.


## IOC Categories

All indicators are maintained in a single consolidated table, including:

- MD5, SHA1, and SHA256 hashes
- Malicious IP addresses
- Malicious domains
- Malicious URLs
- Suspicious filenames
- Email addresses
- Other relevant indicators

## IOC Documentation

Each IOC entry may contain:

| Field | Description |
|---|---|
| Date Added | Date the IOC was documented |
| IOC Type | Hash, IP, Domain, URL, etc. |
| Indicator | Actual IOC value |
| Threat / Context | Associated activity or research context |
| Source | Original intelligence source |
| Confidence | High, Medium, or Low |

## Disclaimer

- Indicators are collected for defensive cybersecurity research.
- Validate indicators before using them in security operations.
- Indicators may become outdated or inactive.
- An IOC match alone does not confirm a security compromise.
- Defang malicious URLs and domains where appropriate.

## Objective

To maintain a centralized and continuously updated collection of malware-related IOCs for threat intelligence sharing, malware research, threat hunting, and defensive security operations.
